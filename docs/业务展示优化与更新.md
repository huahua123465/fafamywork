# 业务展示优化

本次包含前面已提交的柔和排版、多技术项目集定位，以及本次购买流程优化。

- 平台根据项目的 platform 字段生成，与业务题材和关键词组合筛选；关键词覆盖技术标签。未上架的平台只显示上新提示。
- 详情页在截图前展示购买速览，不将截图等同于运行验证，不编造价格或交付承诺。
- 从详情页打开咨询时，自动带上项目名称、slug 编号、技术标签和链接；需求可填写，内容可复制。HTTP 环境不支持剪贴板时可以选中咨询文本手动复制。
- 新增 /buying-guide，说明交付内容、演示、报价、支持、授权和验收需要确认的事项。
- 公开导航改为购买说明，/admin 登录后的界面提供本机浏览数据入口。原 /insights 地址仍保留，不代表服务端统计或受保护的经营后台。

当前未提供统一价格、交付清单、演示验证记录或微信二维码图片，因此未伪造这些资料。现有 60 个项目仍使用原有 Android 技术资料；未来新增平台时需同时填写对应技术与运行信息，不能直接复用 Android 的规格模板。

## 服务器更新

在 /root/fafamywork 检查 git status，先备份和核对未提交改动再更新，不强制覆盖。工作区干净时：

```sh
cd /root/fafamywork
git pull --ff-only origin main && npm run build && cd deploy && docker compose up -d && docker compose restart web
```

保留 deploy/.env 与 deploy/data；不要删除 dist 目录。检查首页、/projects、任一项目详情、/buying-guide、/about，以及后台资料功能。上述更新包含历史排版和项目集定位改动，无需逐个执行旧指令。

# 内容维护指南

## 内容入口

| 文件                            | 用途                                                   |
| ------------------------------- | ------------------------------------------------------ |
| src/content/site.ts             | 网站名称、首屏文案与页脚的默认值                       |
| src/content/author.ts           | 个人介绍、技能等默认值（实际资料在 /admin 填写）       |
| src/content/base-projects.json  | 首批 13 个项目的名称、分类、功能与实现说明（手工维护） |
| src/content/new-projects.json   | 同步脚本生成的其余项目，勿手改                         |
| src/content/project-copy.json   | 人工文案覆盖层，重新生成数据后仍然生效                 |
| src/content/project-assets.json | 自动导入的总览与详细截图                               |
| src/content/platforms.ts        | 项目列表里固定展示的技术平台入口                       |
| src/content/purchase.ts         | 技术规格卡片的文案规则（按平台区分）                   |

开发服务运行期间，保存内容会自动更新页面。最后运行 `npm run build` 检查。

## 更新截图

当前素材源为 `D:/project/项目截图`。替换源图片后运行：

```sh
python -X utf8 scripts/import-project-images.py
npm run build
```

导入脚本需要 Pillow。它按 `MAPPING` 明确列出的十三个目录导入，不会修改原始目录，也不会自动加入其他文件夹。

每项映射依次为 slug、截图文件夹、总览文件名、详细截图子目录。独立图片名以两位数字加短横线或下划线开头，按编号排序。电商取 `全部18页`，花店取 `全部14张`。

生成的 `overview-preview.webp` 是封面预览，`overview.png/jpg` 是未改写的总览原图。`screen-01-preview.webp` 等用于详情缩略图，`screen-01.png/jpg` 等用于高清查看。

`src` 为预览地址，`fullSrc` 为原图，`caption` 为界面名称，`alt` 为图片说明。路径以 `/images/` 开始，不包含 `public`。手动修改自动生成的 JSON 会在重新导入时被覆盖。

## 新增项目

1. 在导入脚本的 `MAPPING` 加入截图目录并运行导入。
2. 在 `base-projects.json` 复制现有条目（或由同步脚本写入 `new-projects.json`），填入与映射一致的唯一 slug。
3. 更新名称、简介、完整说明、功能、实现说明、技术与关键词。
4. 数组位置决定排序（base 在前，new 在后），前六项是首页默认精选；项目列表一次展示全部筛选结果。
5. 非 Android 项目填写 `platform`：`Java Web`、`鸿蒙`、`小程序`，技术规格卡片会换成对应的开发工具与运行环境说明；
   新平台需要在 `purchase.ts` 的 `platformGuides` 补一项。
6. 可选 `price`（如「¥199 起」），填了会优先于后台的全站参考价格显示。

## 润色生成的文案

`new-projects.json` 每次运行 `sync-project-content.py` 都会被整体覆盖，润色内容写在 `project-copy.json`：

- `projects.<slug>`：可覆盖 `tagline`、`description`、`features`（整体替换）、`story`（按位置替换，只写第一段就只换第一段）、
  `previewNotice`、`price`，以及 `imageCaptions`（按截图顺序给每张图命名，条数必须与截图一致）。
- `captions`：全站截图名称翻译，键是导入脚本生成的原始名称，例如 `"Car": "购物车"`。
- `notices`：把同步脚本生成的预览说明整句替换成新的说明。

写文案时以项目总览图里实际出现的页面、字段和按钮为准；总览图里的列表数据是还原时的示例，不要当成项目真实功能来写。

分类可选电商购物、校园学习、旅行生活、社交聊天、管理系统。新增分类需同步 `Category` 类型与 `categories` 数组。

可选的 `demoUrl`、`sourceUrl` 使用真实 HTTP(S) 地址；新增时需同步 `ProjectInfo` 字段声明。未填写演示时显示界面预览，没有源码地址时隐藏源码入口。

介绍仅使用对应项目的文档和模块依据，不复制样例密码、配置或无关文档中的信息。

## 个人信息与图片

`author.ts` 的 email、wechat、github、resume 可以为空。全部联系渠道为空则显示尚未公开联系渠道。填写 avatar 图片路径会替代关于页创作桌面图；当前 `public/images/studio.webp` 是 AI 生成的占位场景。timeline 为空时隐藏经历段落。

关于页首屏标题位于 `src/pages/About.vue`。姓名、联系方式、参考价格等在 `/admin` 填写，保存后立即生效。

## 交互约定

- 搜索、分类和排序保留在 URL，浏览器返回会恢复条件。
- 总览始终第一张，之后为按编号排列的独立截图。
- 详情初始显示八张独立图，可展开其余图片。
- 预览支持缩略图、左右按钮、方向键、Escape、放大/适应窗口和打开原图。
- `/projects/slug?view=preview` 可直接打开预览，关闭后移除预览参数。
- 展示站不执行截图中的购物、聊天或考勤业务，截图内部的控件属于图片内容。

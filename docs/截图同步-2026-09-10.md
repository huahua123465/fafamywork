## 再次同步

先在 `scripts/new-projects.json` 审核新增项目映射，再运行：

```text
python scripts/sync-project-content.py
python scripts/import-project-images.py
npm run test
npm run build
```

技术核对只读取源码，不复制源码、服务凭据或开发者密钥到网站。
